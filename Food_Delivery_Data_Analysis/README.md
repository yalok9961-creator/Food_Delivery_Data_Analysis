
# Food Delivery Data Analysis Using Python

## Project Overview
This project analyzes food delivery data using Python.

## Dataset
The dataset contains 2000 food delivery records.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Revenue Analysis
- Restaurant Analysis
- Cuisine Analysis
- City-wise Orders
- Customer Rating Analysis
- Delivery Time Analysis

## Visualizations
1. Revenue by Cuisine
2. Top 5 Restaurants
3. Orders by City
4. Delivery Time Analysis
5. Customer Rating Distribution

## Files
- Food_Delivery_Analysis.ipynb
- food_delivery_dataset.csv
- food_delivery_dataset.xlsx
- filtered_orders.csv
- food_delivery_analysis.xlsx

## Conclusion
This project helps understand food delivery
business performance through data analysis
and visualization.
